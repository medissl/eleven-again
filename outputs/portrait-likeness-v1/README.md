# Modular portrait likeness review

User-authorized 29 October 2026, after UI checkpoint `a8d1a7f`.

The latest correction covers the recognizable legends and worldwide players in the 200-card catalogue. Review each authored edition against period photographs. Extend the existing interchangeable hair/head/facial-feature pieces, correct recipes and rebuild the existing pixel portraits. **Do not generate complete standalone portraits.** The earlier whole-portrait ImageGen draft was rejected and has never been imported.

The original kit has 51 vector-command parts, eight component categories, nine compositing steps and three semantic palettes on a 96×96 RGBA grid. Every original recipe was compiled and compared against the game: **200/200 are pixel-identical**. `art/portraits/` is the self-contained editable continuation of that kit; preserve the original authoring packages. Runtime uses only the baked PNGs.

`review.json` tracks all 200 cards separately. Pending means not yet individually checked; assembling a distinct face is not evidence of likeness. Preserve IDs, editions, card data, body framing, nearest filtering and the shared native card. Reference photographs are research inputs, never runtime assets. Record sources, visible cues, recipe changes, remaining uncertainty and verification.
