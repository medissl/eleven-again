# Current-game audit

29–30 October 2026. Local source at football checkpoint `ff3e604`, not a hosted index. Graphify lists no Eleven Again repository. The user's new feedback supersedes the previous green/brass layout acceptance; their later rejection also withdraws the graphite/coral v5 proposal. **FC Mobile's whole graphic/styling language is the current reference, from menus throughout.** This audit covers connected systems rather than claiming every code line was reviewed.

| Boundary | Current source and finding | Design response |
|---|---|---|
| Navigation | `ui/campaign_app.gd:render()` removes the old screen, constructs a replacement, then resets its alpha to zero. `settings()` replaces the entire modal on category change; preference changes call it again. | Persistent shell, overlapping page transitions; replace only tab content. Preserve focus/selection/scroll and cancel stale animation callbacks. |
| Squad ownership | `prepare()` creates a private available-plan modal. Only `run_controller.commit_match()` remembers edits. Back discards the draft. | Persistent Squad editor with Apply/Cancel; opponent preparation becomes a separate read-only card pitch. |
| Tactics/positions | `squad/lineup.gd` and `football_ai.gd` supply three formations and ten canonical roles. UI controls largely rebuild the whole preparation screen; deeper AI remains a foundation. | Nine formation diagrams, eleven legal slots, readable position-fit indicators and consolidated tactics drawers. New formations require real shapes/role mapping/tests, never cosmetic dead controls. |
| Run progression | `run_controller.gd` queues recruit/market/coaching after results. `content/campaign/run_rules.json` fixes 12 wins, 3 defeats, prizes 4/7/10m; markets at 3/7/11. Opposition is 24 authored clubs, 60 variants, six origins. | A six-level ascending pyramid with twelve fixtures; original clubs then nations/World Cup. One reward desk, purposeful free signing/cash decision, markets at 3/6/9. |
| Money integrity | `run_state.gd` recomputes cash as 8m + result earnings − acquisitions. Acquisition is the only spending receipt; rerolls do not exist. | Add immutable reroll/cash-choice receipts and ruleset dispatch. A UI-only cash decrement would corrupt saves. |
| Acquisition | `run/acquisition.gd` already handles explicit bands, role slots, unique people, owned/released exclusions and lower-band exhaustion. `AcquisitionScreen` has five full free cards/four market cards per page. | Reuse generator and full cards; improve interaction and price/impact footer. Persist RNG/offer/cost in one journalled action. |
| Card layout | `ui/player_card.gd` already places role beneath OVR, but portrait overlap and a repeated country/role footer weaken it. Native 5:7, six stats, trait and portraits are shared. | Clear OVR → larger position → accurate flag rail. Remove repeated country/role footer; retain template/portraits/stats/trait. Prototype uses a subclass; production untouched. |
| Inspection | `card_inspector.gd` full-screen file repeats much of the card and exposes authoring prose before useful comparison. | A large card with a quiet adjacent player sheet, slot fit, trait, and optional Details/source drawer. Compare in place; restore caller selection on Back. |
| OVR | Decimal formatting appears in origins, opponent scouting, terminal summary, records and saved-XI view. Records store exact sum/11 correctly. | Display `ceili(total/11.0)` everywhere, preserving exact arithmetic and record ordering internally. |
| Font regression | Full runner's equal-digit-width assertion fails with the unchanged Matchday score font (59px vs 90px for four digits at 46px). | Use the already-packaged tabular FontVariation for all score/data roles; verify widths in the new theme. |
| Persistence | `CampaignSession.act()` executes a validated private controller, journals run/profile, then commits. `SaveStore` preserves backups/damaged files. Profile stores acquired versions/records, no permanent power. | Keep transactions and privacy. Version new economics/content; dispatch legacy runs to frozen v1 rules. Never reset the profile. |
| Football | Fixed 60 Hz, 180 active seconds, 1×/2× independence; physical continuity just delivered. Role intelligence/laws/audio remain unfinished. | Retain native rich field/circles only in live play. This management redesign does not claim football AI/audio complete. |
| Audio | Volume setting exists; no implemented music/effects library was found in the prior handoff/current match/UI scan. | Design independent sound/music controls, but only enable wired audio controls in production. No fake implemented-sound claim. |
| Content | Campaign hard-validates 6 origins/24 clubs/60 variants/1,356 definitions. `Campaign.VERSION=campaign_v1`; state schema 3 rejects other versions. | Expanded origins and new rivals are authored data/migration work, not label-only changes. Preserve old definitions and legacy opponents for saved runs. |
