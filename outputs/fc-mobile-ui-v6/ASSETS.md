# Asset provenance

- Existing portraits, fictional run portraits and the full native card/data model are read from current project assets. None of the200 portrait PNGs/recipes or card definitions was edited. The new shared frame/label adapter changes presentation only.
- `fonts/Saira-Variable.ttf`, `fonts/Saira-Italic-Variable.ttf`: Saira by Omnibus-Type, sourced from the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/saira), upright/italic width+weight variable files. [Metadata](https://raw.githubusercontent.com/google/fonts/main/ofl/saira/METADATA.pb) records the upstream project/commit. SIL Open Font License text retained (trailing whitespace trimmed) as `Saira-OFL.txt`; SHA-256 hashes recorded in the package manifest. One family supplies body 500, actions 600, heavy 800 and italic heavy display, width 90, with tabular figures. Existing Source Sans is a missing-symbol fallback. Unused Rajdhani specimens were moved to ignored `.godot/font-specimens/` and are not distributed.
- `ability_icons.gd`: 36 original white SVG line glyphs authored for the current trait registry. They rasterize locally at 64×64 and cache as native textures. No external icon font, generated portrait, badge power or new gameplay trait is introduced. `card_style.gd` draws one original metallic frame/gradient/palette for every definition; no individual card bitmap is reauthored.
- 42 contemporary/football-country flags: static SVG subset of `lipis/flag-icons`, pinned **v7.3.2**, fetched from `https://raw.githubusercontent.com/lipis/flag-icons/v7.3.2/flags/4x3/`. Football codes map explicitly to ISO assets, including ENG/gb-eng, SCO/gb-sct, WAL/gb-wls, NIR/gb-nir and GUI/gn. MIT licence retained verbatim in `flags/LICENSE`. `origins.json` contains 32 proposed selectable origins; ten extra contemporary flags support catalogue metadata. [Upstream](https://github.com/lipis/flag-icons/tree/v7.3.2).
- Historical URS flag, for the existing Yashin edition: [Wikimedia source/file/licensing record](https://commons.wikimedia.org/wiki/File:Flag_of_the_Soviet_Union.svg), [original SVG](https://upload.wikimedia.org/wikipedia/commons/a/a9/Flag_of_the_Soviet_Union.svg). Source records it as a public-domain state symbol. Historical metadata remains URS rather than silently substituting Russia. This asset is not an origin choice.
- `flags/checksums.json` records SHA-256 for all 43 SVGs. Godot decodes these static files locally; no font/icon network access, CSS package or new runtime dependency.
- `art/arena.png`: original image generated with the built-in image-generation tool on 30 October 2026, 1672×941. Prompt specified an empty floodlit night stadium, dark blue architecture, natural turf, no players, writing, sponsors, brands or logos. Used only as the management/menu environment. It does not replace native gameplay turf or field markings.
- `art/club-crests.png`: original transparent 1280×1280, four-crest 2×2 atlas generated with the built-in image-generation tool on 30 October 2026. Quadrants: Rive Athletic bridge/river navy-cyan; Isar Union red mountain/river; Crown Vale burgundy/platinum crown; Forge Sporting charcoal/copper gate. Each is extracted as an AtlasTexture region in `components.gd`. They are original fictional identities, not official club marks. Remaining rival/content admission is implementation work. Native vector geometry remains a fallback.
- No player portrait was generated, repainted or edited for this revision. The 200-player likeness milestone stays settled.
- User-supplied screenshots/FUT image and official FC Mobile screenshots were references only. EA/Balatro/Last Flame images are not distributed as game assets. Local EA research images live in ignored `.godot/fc-mobile-references/`, outside this package.
